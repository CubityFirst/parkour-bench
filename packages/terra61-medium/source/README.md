# Skyline / Run

## Getting started

Run `npm install` and `npm run dev`, then open the local URL displayed in the terminal in a desktop browser. Run `npm run build` to create a production build in `dist`.

Click **Start running** to capture the mouse. Use WASD to move, Shift to sprint, and Space to jump; hold Space longer for a higher jump. Hold Ctrl or C to slide, press E to vault or mantle a nearby low ledge, and press R to return to the latest checkpoint. Escape releases the mouse and pauses the run.

Follow the red markings across the rooftops. Jump beside the red wall to wall-run, then jump away from it when needed. Reaching the red gate finishes the course; the best time is saved in the browser. Mouse sensitivity and reduced camera motion can be adjusted in the menu.
