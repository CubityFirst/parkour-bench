# Skyline Relay

A first-person rooftop time trial built with Three.js and TypeScript.

Use Node.js 20.19+ or 22.12+. Run `npm install` followed by `npm run dev`, then open the local URL in a desktop browser. Click **Start run** to capture the mouse. Use WASD to move, Shift to sprint, Space to jump, Ctrl or C to slide, E to vault or mantle, and R to return to the last checkpoint. Escape pauses and releases the cursor. Adjust sensitivity and camera motion in the menu. Follow the red markers to the finish; your best time is stored locally.
