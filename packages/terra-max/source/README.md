# Skyline Flow

An original first-person rooftop parkour run built with Three.js, TypeScript, and Vite. The course is intentionally designed around readable red route markers, white high-rise rooftops, sprint jumps, a slide gate, vaults, checkpoints, and a wall-run gap.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, then select **START RUN**.

## Controls

| Input | Action |
| --- | --- |
| WASD + mouse | Move and look |
| Shift | Sprint |
| Space | Jump / wall jump |
| Ctrl or C | Slide |
| E | Vault highlighted barriers |
| R | Restart from latest checkpoint |
| Esc | Pause / release mouse |

The game stores your best completion time in local browser storage.
