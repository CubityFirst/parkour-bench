# Rooftop Flow

An original first-person rooftop parkour run built with Three.js, TypeScript, and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (normally `http://localhost:5173`). Click **RUN THE COURSE**, then click the game view to lock the mouse.

## Controls

- `WASD` move and strafe
- Mouse look
- `Shift` sprint
- `Space` jump (including a wall jump)
- `Ctrl` / `C` slide
- `E` vault a low obstacle
- `R` return to the latest checkpoint
- `Esc` pause / release mouse

The red line highlights the intended route. Cross the red finish frame to record a locally saved best time.
